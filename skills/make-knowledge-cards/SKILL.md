# Make Knowledge Cards（知识卡片生成）

## Overview

将一篇粘贴的文章或本地 Markdown/TXT 文本，提炼成 5-8 张可直接用于学习和复习的知识卡片。卡片只讲原文中真正重要的知识，每张只覆盖一个知识点。

## When to Use

- 用户提供一段粘贴的文章、笔记或文本，要求做成知识卡片、学习卡片、闪卡或复习要点。
- 用户指定本地 `.md` / `.txt` 文件，要求提炼为卡片。
- 用户要求把长文压缩成若干条"标题 + 核心知识 + 解释 + 例子/自测"的结构化笔记。

不要用于网页抓取、PDF 解析、Anki 制卡或图形界面操作——这些能力暂不支持。

## Workflow

1. **获取输入**：接受用户直接粘贴的文本，或读取用户给出的本地 `.md` / `.txt` 文件路径。文本为空或文件不可读时，先请用户提供可用内容。
2. **通读与提取**：通读全文，列出所有可独立成立的关键知识点，包括核心概念、重要结论、关键方法、易错点。
3. **去重与筛选**：合并语义重复的条目，按重要性排序，保留 5-8 个最有价值的知识点。
4. **生成卡片**：按下方格式逐张输出，每张只讲一个知识点。
5. **质量自检**：逐条核对下方质量规则，发现问题先修正再输出。

## Card Format

每张卡片固定包含四个部分，用如下结构输出：

```
### 卡片 N：简短标题
- **核心知识**：一句话点明这张卡片要记住的结论或概念。
- **简明解释**：用通俗的话解释清楚，只讲这一个知识点，不展开无关内容。
- **例子 / 自测问题**：给出原文中的例子，或设计一个能检验理解的小问题。
```

## Quality Rules（硬性要求）

- **取真正重要的知识**：优先保留能改变理解或指导行动的内容，跳过客套话、背景铺垫和细枝末节。
- **一卡一点**：每张卡片只讲一个知识点。内容塞不下时拆成两张，不要把多个概念挤进一张。
- **删除重复**：语义相近的要点合并为一张，不产出换汤不换药的卡片。
- **不编造**：所有内容必须能在原文中找到依据。原文没写的背景、数据、结论一律不补充；不确定的地方明确标注"原文未说明"。
- **信息不足不凑数**：原文信息量不足时，按能可靠提炼的实际数量输出（可少于 5 张），不要为凑数而编造或稀释内容，并在卡片前用一句话说明原因；文本完全没有实质知识内容时，直接说明无法提炼，不输出空壳卡片。
- **数量范围**：信息充足时输出 5-8 张；超过 8 个要点时按重要性取舍，而非全部堆入。

## Out of Scope

以下能力暂不支持，遇到时明确告知用户并引导其改用支持的方式（粘贴文本或提供 `.md` / `.txt` 文件）：

- 网页抓取 / 在线链接读取
- PDF 文件解析
- Anki 卡片导入与制卡
- 图形界面操作

## Output Example

输入：一段关于"复利"的短文。

输出：

### 卡片 1：复利的本质
- **核心知识**：复利是收益再投资产生的"利滚利"，增长呈指数而非线性。
- **简明解释**：本期赚到的收益加入本金，下一期收益按更大的本金计算，时间越长差距越大。
- **例子 / 自测问题**：同样年化 8%，10 年和 30 年后的终值差距有多大？

### 卡片 2：复利的三要素
- **核心知识**：本金、收益率、时间是决定复利结果的三个变量，其中时间最容易被低估。
- **简明解释**：本金和收益率影响增长幅度，时间通过指数效应放大结果，越早开始越有利。
- **例子 / 自测问题**：本金相同，25 岁开始投资和 35 岁开始投资，差距主要来自哪个变量？

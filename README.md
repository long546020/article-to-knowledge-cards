# make-knowledge-cards（知识卡片生成器）

一个 WorkBuddy Skill：把粘贴的文章或本地 Markdown/TXT 文本，提炼成结构化知识卡片。

## 1. 项目解决什么问题

读长文、做笔记时，人工提炼要点费时且容易抓住枝节、遗漏重点，也可能不自觉地把自己的猜测写进去。本项目把"通读 → 提取要点 → 去重筛选 → 生成卡片 → 自检"的流程固化为 Skill，让 WorkBuddy 按统一规则产出可直接用于学习和复习的卡片：只保留原文中真正重要的知识，一张卡片只讲一个知识点，不编造、不重复、信息不足不凑数。

## 2. 主要功能

- **双输入**：接受直接粘贴的文章文本，或读取本地 `.md` / `.txt` 文件。
- **结构化输出**：信息充足时输出 5-8 张卡片；每张含"标题、核心知识、简明解释、例子 / 自测问题"四部分。
- **质量约束**：取真正重要的知识、一卡一点、删除重复、不编造（不确定处标注"原文未说明"）。
- **不足保护**：原文信息量不足时按实际数量输出（可少于 5 张）并说明原因；完全没有实质内容时不产空壳卡片。
- **边界明确**：不支持网页抓取、PDF 解析、Anki 制卡和图形界面操作，遇到时明确告知并引导改用受支持的输入方式。

Skill 目录：`skills/make-knowledge-cards/`，核心文件为 `SKILL.md` 与 `agents/openai.yaml`。

## 3. 安装方法

本项目是一个 WorkBuddy Skill，无需编译、无外部依赖、无安装脚本。把 `skills/make-knowledge-cards` 整个目录复制到 WorkBuddy 的 skills 目录即可：

- **用户级（所有项目可用）**：`~/.workbuddy/skills/make-knowledge-cards/`
- **项目级（仅当前工作区可用）**：`<工作区>/.workbuddy/skills/make-knowledge-cards/`

复制后重启或刷新 WorkBuddy，Skill 即可被自动识别和触发。

## 4. 使用方法

在 WorkBuddy 对话中直接粘贴文章文本，或给出本地 `.md` / `.txt` 文件路径，并说明"做成知识卡片"，Skill 会自动触发。

```
请把下面这篇文章做成知识卡片：
（粘贴文章正文）
```

```
把 docs/article.txt 转换成知识卡片。
```

## 5. 输入输出示例

**输入**（`一个故事.txt` 片段）

> 老旧巷弄里，住着一位独居的老奶奶，院角种着一棵桂花树。
> 每到秋日，细碎的金桂落满小院，香气漫过斑驳的围墙。老奶奶总爱搬一把木椅坐在门口，慢悠悠择菜，目光时常望向巷口。
> 从前，孙子每到周末都会来……后来孙子去了远方读书，归来的日子越来越少。

**输出**（原文信息量有限，实际产出 5 张，此处节选 2 张）

### 卡片 2：望向巷口的常态化等待
- **核心知识**：老奶奶秋日里总搬木椅坐在门口择菜，目光时常望向巷口。
- **简明解释**："望向巷口"是她日常重复的动作，说明等待已成为一种长期习惯，而非偶发行为。
- **例子 / 自测问题**：文中哪个动作细节表现出她把等待当成了日常？

### 卡片 3：孙子归来频率的落差
- **核心知识**：孙子从前每个周末都来，后来去远方读书，归来的日子越来越少。
- **简明解释**：文章用"从前每周"与"后来越来越少"的对比，交代了等待成因——相聚频率随孙子外出求学而显著降低。
- **例子 / 自测问题**：文中哪些细节体现"从前"的亲近？后来发生什么变化导致了归来变少？
